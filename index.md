# Momentum Monitor Weekly Sync

Momentum Monitor Weekly Sync is a personal utility that copies CSV files from a designated local folder to a designated folder in the user's Google Drive.

## Features

- One-way upload from a local folder to Google Drive
- Creates new files and updates changed files
- Does not automatically delete remote files
- Runs only on the user's Mac
- Stores operation logs locally

This application is used only for personal file backup and synchronization.
