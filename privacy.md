# Privacy Policy

Last updated: October 2, 2026

Momentum Monitor Weekly Sync uses the Google Drive API to synchronize files selected by the user from a local folder to a folder in the user's Google Drive.

## Information accessed

The application may access:

- File and folder metadata in the user's Google Drive
- Files selected for synchronization
- A Google OAuth authorization token stored on the user's computer

## How information is used

Google Drive access is used only to:

- Locate the Google Drive folder configured by the user
- Upload new files
- Compare and update existing files

The application does not call the Google Drive delete API and does not automatically delete remote files.

## Storage and sharing

- OAuth credentials and tokens are stored only on the user's local computer.
- Files and authentication information are not sent to any separate external server.
- User information is not sold or shared with third parties.

## Data retention

The application does not operate an external server or database and therefore does not retain user data outside the user's computer and Google Drive.

## Revoking access

The user may revoke access at any time from the [Google Account connections page](https://myaccount.google.com/connections).
